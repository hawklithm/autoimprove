# AutoImprove Status

Check the MCP tool `health_check` from autoimprove-core server to show:
- Storage initialization status at `~/.autoimprove/`
- Number of rules in the knowledge base
- Recent activity and tech stack coverage
- System health status

Call the MCP tool directly using available MCP tools from autoimprove-core.
