# AutoImprove Rules

Call the MCP tool `search_knowledge` from autoimprove-core server to:
- List all rules grouped by priority (critical, high, medium, low)
- Show rule IDs, types, confidence scores, and keywords
- Display statistics about the knowledge base

Use MCP tools from autoimprove-core to search and display rules.
