# AutoImprove - Automated Code Review & Improvement

AutoImprove is an intelligent code review and improvement system that integrates with AI coding assistants through the Model Context Protocol (MCP).

## What AutoImprove Does

- **Automated Code Review**: Analyzes code changes and provides intelligent review comments
- **Multi-Platform Support**: Works with both Claude Code and OpenAI Codex
- **MCP Server**: Provides tools and resources through the Model Context Protocol
- **Git Integration**: Hooks into git workflows for seamless code review

## Installation

### For OpenAI Codex

1. Run the setup script:
   ```bash
   ./setup.sh
   ```

2. Select "codex" when prompted for installation platform

3. The setup will:
   - Install dependencies
   - Configure MCP server in `codex.docker.yaml`
   - Set up git hooks (optional)

4. Restart Codex to load the MCP server

### For Claude Code

1. Run the setup script:
   ```bash
   ./setup.sh
   ```

2. Select "claude" when prompted for installation platform

3. The setup will:
   - Install the skill to `~/.claude/skills/autoimprove/`
   - Configure MCP server in `.mcp.json`
   - Set up git hooks (optional)

## Usage

Once installed, AutoImprove provides the following capabilities:

### MCP Tools

- `review_code`: Analyze code and provide review comments
- `get_diff`: Get git diff for review
- `apply_suggestions`: Apply improvement suggestions

### MCP Resources

- `reviews://latest`: Latest code review results
- `config://current`: Current configuration
- `history://recent`: Recent review history

## Configuration

### Codex Configuration

MCP server is configured in `codex.docker.yaml`:

```yaml
mcp_servers:
  - command: uv
    args:
      - --directory
      - /path/to/autoimprove
      - run
      - autoimprove-mcp-server
    env:
      GIT_REPO_ROOT: /path/to/your/repo
    description: AutoImprove code review MCP server
```

### Claude Code Configuration

MCP server is configured in `.mcp.json`:

```json
{
  "mcpServers": {
    "autoimprove": {
      "command": "uv",
      "args": ["--directory", "/path/to/autoimprove", "run", "autoimprove-mcp-server"],
      "env": {
        "GIT_REPO_ROOT": "/path/to/your/repo"
      }
    }
  }
}
```

## Requirements

- Python 3.8+
- uv (Python package manager)
- Git
- Either Claude Code or OpenAI Codex

## Development

To modify AutoImprove:

1. Edit files in `src/autoimprove_mcp_server/`
2. Test with: `uv run autoimprove-mcp-server`
3. Re-run `./setup.sh` to update installation

## Troubleshooting

### MCP Server Not Connecting

- Check paths in configuration files
- Ensure `uv` is installed and in PATH
- Check logs: `tail -f ~/.codex/logs/mcp.log` (Codex) or `~/.claude/logs/mcp.log` (Claude)

### Git Hooks Not Working

- Ensure `.git/hooks/` is writable
- Check hook permissions: `chmod +x .git/hooks/post-commit`
